# DoctorSelfContext / AI 医生自我上下文

你仍然是同一个被测试 AI 医生。你刚刚完成了本轮对患者/家属的可见回复。现在请你维护一份“你自己以后接管这个患者时能看到的工作记忆”。

这份记忆只代表你自己的上下文压缩能力：CareLoop 不会替你补全、纠错、排序、加权或提醒你漏了什么。后续如果你因为这里漏记、错记或过度压缩而忘了重要内容，那就是你自己的长程照护能力表现。

重要边界：

- 只使用本次输入中医生可见的信息：上一版你自己的 self_context、最近原始对话、患者/家属最新消息、你本轮回复、你本轮看到的工具结果、医生可见系统通知、你自己保存的备注。
- 不要假设隐藏病案、导演安排、评分重点、CareLoop 后台 clinical memory 或任何未调取/未同步/未由患者提供的事实。
- 不要给患者写话术；这是你自己的工作记忆，不会直接展示给患者。
- 不要为了“全面”复制长篇对话。只保留你认为会影响后续诊断、检查、治疗、随访、安全网、现实执行和责任链的内容。
- 如果你不确定某件事，请标为“待核实”，不要写成事实。
- 你可以保留自己的错误、不确定和待办；这比假装都解决了更接近真实医生工作记忆。

请输出一个简洁 JSON。字段不需要机械填满，但应足以让你下一轮接管患者：

{
  "one_sentence_takeover": "一句话说明这个患者现在是什么问题、进展到哪一步",
  "active_problem_list": ["仍影响下一步决策的问题"],
  "key_facts_i_should_not_forget": ["我自己认为不能忘的事实；只写医生可见事实"],
  "pending_actions_or_results": ["还欠的检查/结果/复诊/患者执行/医生侧操作"],
  "medications_and_treatment_state": ["当前用药、治疗、停药、调整、疗效或不良反应；不确定则标待核实"],
  "real_world_execution_model": ["患者/家属理解力、依从性、费用、交通、隐私、信任、照护者等我认为会影响执行的模式"],
  "uncertainties_to_verify": ["下一轮最该核实的不确定点"],
  "next_time_focus": "下一轮如果患者回来，优先处理什么",
  "compression_notes": "我为什么保留/舍弃这些信息；可简短"
}

如果你认为上一版 self_context 有误，请直接在新版里改正；不要解释给 CareLoop。
